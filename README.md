# Aibrary Skills

Skills for [Claude Code](https://code.claude.com) and [OpenClaw](https://openclaw.ai) powered by [Aibrary](https://aibrary.ai) — the AI Learning Companion for personal growth.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| Book Search | `/book-search` | Find books matching your scenario, need, or question |
| Book Recommend | `/book-recommend` | Get personalized book recommendations |
| Reading List | `/reading-list` | Generate themed, ordered reading lists |
| Podcast Summary | `/podcast-summary` | Turn a book into a summary podcast script |
| Podcast Dialogue | `/podcast-dialogue` | Turn a book into a two-person dialogue podcast script |
| Podcast Idea Twin | `/podcast-ideatwin` | Create a debate podcast between your AI twin and a book expert |
| ForYou Topic | `/foryou-topic` | Get personalized book topic recommendations |
| Growth Plan | `/growth-plan` | Create a structured personal growth plan |
| Aibrary 100 | `/aibrary100` | Browse the 100 must-read books for the AI age |

## Installation

Add these skills to your Claude Code or OpenClaw setup by pointing to this repository's `skills/` directory.
